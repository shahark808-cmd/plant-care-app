# יומן אימונים (שלבים 1-3: כוח, תזונה וריצה)

PWA אישית בעברית (RTL, mobile-first) לפי האפיון. Vite + React + TypeScript, אחסון מקומי ב-IndexedDB (Dexie), עובדת אופליין.

```bash
cd fitness
npm install
npm run dev      # פיתוח
npm test         # בדיקות יחידה לאלגוריתמים (סעיף 13 באפיון)
npm run build    # tsc + build + service worker
```

## מה קיים בשלב 1
- מאגר של 69 תרגילים בעברית עם ביצוע, דגשים וטעויות נפוצות (`src/data/exercises.ts`). **טיוטה שדורשת בדיקה אנושית לדיוק.**
- בונה אימונים: הוספה מהמאגר, גרירה לסידור, סטים/טווח/משקל/צעד/מנוחה/הערה, סופר-סט, שכפול, תבניות A ו-B.
- אימון פעיל: מילוי אוטומטי מהצעת האלגוריתם עם נימוק, טיימר מנוחה, סוגי סטים, חימום אוטומטי, מחשבון דיסקיות, החלפת תרגיל, דירוג מאמץ, שיא אישי, מסך דלוק, שמירה אוטומטית והמשך אחרי סגירה.
- אלגוריתם Double Progression כפונקציות טהורות (`src/lib/progression.ts`) וכל הספים ניתנים לעריכה בהגדרות.
- היסטוריה, 1RM משוער (Epley), גרף לכל תרגיל, סטים שבועיים לשריר, הצעת דלוד, מצב כהה, ייצוא וייבוא JSON.

## מה קיים בשלב 2 (תזונה)
- נתוני פרופיל וחישוב יעדים (Mifflin-St Jeor, חלבון 1.8 ג׳/ק״ג, שומן 0.9 ג׳/ק״ג), עם עריכה ידנית של כל יעד (`src/lib/nutrition.ts`, מכוסה בבדיקות).
- מסך יומי עם סרגלי קלוריות, חלבון, פחמימות ושומן, ארבע ארוחות, ניווט בין ימים, ופס תזונה במסך "היום".
- הוספת אוכל: חיפוש במאגר של 40 מזונות בעברית (ערכים משוערים) עם אחרונים בראש, כמות בגרמים או ביחידות, ארוחות שמורות, הוספה ידנית שנשמרת במאגר האישי, וברקוד דרך Open Food Facts (הקלדה, או סריקה במצלמה בדפדפנים שתומכים ב-BarcodeDetector). מוצר שנמצא נשמר במאגר האישי.
- מעקב משקל גוף עם ממוצע נע (EMA), והצעה להוסיף 150 קלוריות כשבמטרת עלייה המגמה שטוחה 2-3 שבועות.

## מה קיים בשלב 3 (ריצה, בלי Strava)
- יומן ריצות: רישום ידני (מרחק, זמן, דופק, תחושה, הערה), קצב מחושב אוטומטית, עריכה ומחיקה, וסיכום ק״מ שבועי.
- תוכנית 10 ק״מ ל-12 שבועות (`src/data/runPlan.ts`) עם מעקב בצע מול תכנון, חזרה על שבוע או דילוג, וכפתור "לא מרגיש 100%".
- כללי בטיחות (`src/lib/running.ts`, בבדיקות): התראה על עלייה שבועית של יותר מ-10%, התראה על ריצה איכותית בטווח 24 שעות מאימון רגליים כבד, והודעת הפניה לאיש מקצוע בכאב.
- איחוד כפילויות לפי אותו יום, מרחק בטווח 5% וזמן בטווח 10%. הרישום הידני תמיד גובר ונתונים חסרים (דופק, מזהה Strava) משלימים אותו.
- ייבוא קובץ GPX. **FIT לא נתמך עדיין** (פורמט בינארי).

## לא נבנה בשלב 3
- סנכרון Strava (OAuth, webhook, טוקנים) דורש פונקציות שרת ויצירת אפליקציית API ב-Strava. המבנה (`Run.source`, `stravaId`, איחוד כפילויות) כבר מוכן לקבל אותו.

## לא נבנה בשלב 2
- הערכת ארוחה מתיאור חופשי (Claude API) דורשת פונקציית שרת כדי לא לחשוף מפתח.
- מאגר ערכים תזונתיים ישראלי: לא אומת שיש גישה, ולכן המאגר המובנה הוא כללי וקטן.
- תפריט שבועי ורשימת קניות (מוגדרים באפיון כשלב מאוחר), וחישוב TDEE אמפירי.

## החלטות והבדלים מהאפיון
- בתרגילי בידוד (`isolation`) לא מרחיבים טווח חזרות לפני עלייה, כי מקרה הבדיקה 3 (הרמות צד 5 ק״ג, צעד 1) מצפה ל-6 ק״ג ולא להרחבת טווח. ההרחבה חלה על תרגילים מורכבים ורגליים (מקרה 2).
- העלייה מעגלת את **הקפיצה** לצעד ולא את המשקל החדש, כדי שמקרה 1 (42 ← 44.5) יתקבל.
- יעד ירידה במשקל מחושב כתחזוקה פחות 400 (אמצע הטווח 300-500). מקדם פעילות: עד 3 אימונים 1.375, 4-5 אימונים 1.55, 6 ומעלה 1.725.
- ריצה איכותית מסומנת ידנית ברישום הריצה, והבדיקה מול אימון רגליים משתמשת בסטים של תרגילי רגליים (לפחות 6 סטים נחשבים כבד). גם הסנכרון בין מכשירים (Supabase) ו-Strava/PubMed/Claude API לא נבנו עדיין, והם דורשים פונקציות שרת.
